# 스피커와 음파

## 문서 범위

이 문서는 스피커 오브젝트의 공통 물리 범위를 정의한다. 음량 SETTINGS가 이 오브젝트에 미치는 규칙은 [설정 기믹](settings_gimmicks.md)을 따른다.

## 공통 규칙

- 스피커 본체는 항상 `5T × 9T`(`200 × 360px`)다. ROOM별 배치에서는 위치와 연결부 장착 방향만 지정한다.

- 스피커는 본체 중심에서 360도 방향으로 음파 영향을 만든다.
- 최대 영향 반경은 효과음 음량 100%에서 `27T`(`1080px`)다. 실제 반경은 이 최대값에 현재 효과음 음량 비율을 곱한다.
- 영향 범위 안에 들어온 이동 가능한 대상은 음파 방향으로 밀린다. 밀어내기 기준 속도는 `1900px/s`이며, 효과음 음량은 이 효과의 강도와 시각 표현에도 같은 비율로 연결된다.
- 음파는 고체에 막히지 않는다. 파문은 월드 고체 위에 표시하되, 고체 표면을 지나는 짧은 구간만 옅게 표현한다. 플레이어와 UI는 파문보다 앞에 표시한다.
- 연결부는 장착 방향에서 지지판 높이와 `1T` 이상 겹치는 가장 가까운 고정 플랫폼 면에 끝을 맞춘다. ROOM별 배치에서 왼쪽 또는 오른쪽 연결을 명시할 수 있으며, 적합한 고정 플랫폼이 없을 때만 기본 `3T` 거리의 외곽 방향 지지 위치를 사용한다.
- K 본체와 음파 효과의 ASCII 표기 방법은 [ROOM 맵 가이드](../rooms/ROOM_MAP_GUIDE.md)를 따른다.

ROOM 문서는 스피커 범위 안팎의 배치가 해법에 어떤 결과를 만드는지만 기록한다.
