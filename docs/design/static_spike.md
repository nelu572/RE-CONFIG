# 정적 가시

## 문서 범위

이 문서는 정적 가시의 공통 동작, 충돌, 시각과 기본 크기를 정의한다. ROOM 문서는 가시의 배치와 그것이 만드는 경로 판단만 기록한다.

## 공통 규칙

- 정적 가시는 `StaticSpikeDef`로 배치하는 고정 위험물이다. 자체 AI·이동·적 수·적 전투 상태·ROOM 클리어 조건에는 포함하지 않는다. M1/M2는 화면 X축 이동에서 정적 가시를 벽처럼 충돌하며, 중력축에서는 정적 가시를 지지면으로 취급하지 않는다.
- 기본 충돌 범위는 폭 `1T`, 높이 `0.5T`다. 충돌 범위 안의 삼각형 가시 자체가 플레이어와 닿으면, M1/M2 및 기존 위험물과 같은 ROOM 리셋 처리를 시작한다.
- 가시는 플랫폼 면에 붙이거나 허공에 독립 배치할 수 있다.
- 가시의 꼭짓점 방향은 회전값과 함께 바뀐다. `0°`는 위쪽, `90°`는 오른쪽, `180°`는 아래쪽, `270°`는 왼쪽을 향한다. 충돌 삼각형과 렌더링은 같은 회전을 사용한다.

## 시각 사양

- 선명한 빨강의 꽉 찬 뾰족한 삼각형만 그린다.
- 적 본체, 원형 외곽선, 눈, 받침대, 별도 그림자는 사용하지 않는다.

## ROOM 표기

`M`과 회전용 `N`/`L`/`R`의 ASCII 표기·코드 생성은 [ROOM 맵 가이드](../rooms/ROOM_MAP_GUIDE.md)를 따른다.
