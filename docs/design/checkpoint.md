# 체크포인트

## 문서 범위

이 문서는 체크포인트의 공통 활성화, 리스폰, 시각 표현을 정의한다. ROOM 문서는 체크포인트의 실제 배치와 해당 위치가 구간 진행에 미치는 영향만 기록한다.

## 공통 규칙

- 각 체크포인트는 비충돌 `1T × 1T` 영역이며 ASCII에서는 `C`로 표시한다. 한 ROOM에 여러 `C`를 둘 수 있다.
- 플레이어가 어느 체크포인트 영역에 닿으면 즉시 활성화되며, 이전 활성 체크포인트는 해제된다.
- 활성화 후 사망하거나 `R`로 ROOM을 리셋하면 플레이어는 가장 최근에 활성화한 체크포인트 위치에서 다시 시작한다. 체크포인트는 누적하지 않으며, 다른 ROOM 오브젝트는 기존 ROOM 리셋 규칙대로 초기화된다.
- 체크포인트는 현재 ROOM에 머무는 동안 유지되며, ROOM을 나갔다가 다시 입장하면 비활성 상태로 시작한다.
- 깃대와 받침은 밝은색, 깃발은 빨간색 삼각형으로 그린다.
- 깃발 삼각형은 체크포인트 영역을 기준으로 가로 `0.6T`, 세로 `0.35T` 크기로 그린다.
- 현재 활성 체크포인트의 깃발은 `0.65초` 동안 깃대 아래로 내려가며, 완전히 내려간 상태를 유지한다. 이전 체크포인트의 깃발은 초기 상태로 돌아간다.
- 현재 체크포인트를 사용하는 ROOM은 ROOM 10뿐이다.

`C`의 ASCII 표기와 코드 반영 방식은 [ROOM 맵 가이드](../rooms/ROOM_MAP_GUIDE.md)를 따른다.
