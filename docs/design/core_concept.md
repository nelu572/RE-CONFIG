# 핵심 콘셉트

## 게임 한 줄 소개

`RE:CONFIG`는 평범한 설정 메뉴처럼 보이는 값을 키보드로 변경해 스테이지의 규칙과 상태를 조작하고 퍼즐을 해결하는 미니멀 퍼즐 게임이다.

## 핵심 게임 콘셉트

플레이어는 처음에는 일반적인 게임 설정처럼 보이는 메뉴를 사용한다. 그러나 진행하면서 각 설정이 게임 월드와 직접 연결되어 있으며, 설정 변경이 벽, 중력, 음파 같은 월드 규칙을 바꾼다는 사실을 학습한다.

핵심은 특정 요소를 단순히 삭제하는 것이 아니다. 핵심은 `JUMP`, `GRAVITY`, `COLLISION`, `VOLUME`처럼 설정과 시스템 규칙으로 보이는 값을 바꾸고, 그 변화가 월드에 즉각적이고 시각적으로 이해 가능한 방식으로 드러나며, 플레이어가 그 변화를 이용해 문제를 해결하는 것이다.

## 플레이어의 기본 목표

- 각 스테이지의 EXIT에 도달한다.
- 월드 안에서 직접 행동하는 것만으로 해결되지 않는 상황을 설정 변경으로 우회한다.
- 설정값과 월드 변화의 관계를 관찰해 다음 퍼즐에 적용한다.

## 핵심 게임 루프

1. 짧고 제한된 스테이지에 진입한다.
2. 이동, 점프 등 기본 조작으로 현재 장애물을 확인한다.
3. 설정 UI를 열고 하나 이상의 값을 변경한다.
4. 월드에서 바뀐 규칙이나 상태를 관찰한다.
5. 바뀐 상태를 이용해 EXIT에 도달한다.
6. 이후 스테이지에서 이미 배운 설정 규칙을 변형하거나 조합해 사용한다.

## 조작 방식

### 확정 방향

- 게임 플레이와 설정 UI 모두 키보드만 사용한다.
- 설정 UI는 마우스 슬라이더를 전제로 하지 않는다.
- 설정값은 ON/OFF, 또는 몇 개의 명확한 단계/선택지 중 하나를 고르는 방식으로 설계한다.

### 현재 프로토타입 참고

현재 빌드에는 이동, 점프, 설정 열기/닫기, 카테고리 이동, 항목 선택, 토글 입력이 구현되어 있다. 이는 현 구현 참고 사항이며, 최종 조작 체계 전체가 확정되었다는 의미는 아니다.

## 설정 UI 구조

### 확정 방향

- 설정 UI는 게임 월드와 분리된 단순 옵션 화면이 아니라 퍼즐 해결을 위한 조작 장치다.
- 설정을 변경하면 가능하면 즉시 월드의 시각적 변화가 보여야 한다.
- 플레이어가 설명문을 읽지 않아도 값을 바꿔보고 결과를 관찰하며 규칙을 이해할 수 있어야 한다.

## 설정 카테고리

현재 UI의 기본 카테고리는 다음과 같다.

- 게임
- 오디오
- 시스템

이 카테고리 구조는 현재 기준이며 향후 변경될 수 있다.

## 기믹 설계 원칙

- 각 설정은 단순한 메뉴 장식이 아니라 월드 규칙과 연결되어야 한다.
- 수치 맞추기 자체가 퍼즐이 되지 않도록 한다.
- `47%` 같은 정확한 값을 찾게 하기보다 ON/OFF 또는 소수의 명확한 단계를 사용한다.
- 초반에는 설정 하나를 독립적으로 학습시킨다.
- 충분히 학습된 뒤에 여러 설정을 조합하는 레벨을 검토한다.
- 후보 아이디어는 레벨 설계나 구현 검증 전까지 확정하지 않는다.
