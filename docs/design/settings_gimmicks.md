# 설정 기믹

이 문서는 설정 카테고리별 기믹의 확정 상태와 기본 작동 원리를 정리한다. 확정되지 않은 항목은 후보 또는 검토 중으로 유지하며, 세부 수치와 최종 상호작용을 임의로 결정하지 않는다.

## 현재 SETTINGS 구현 상태

| 카테고리 | 항목 | 현재 상태 | 월드 영향 |
| --- | --- | --- | --- |
| 게임 | 캐릭터 유연성 | 프로토타입 구현 | 플레이어 충돌 크기와 통과 가능한 통로가 바뀐다. |
| 게임 | 기믹 속도 | 프로토타입 구현 | 피스톤·움직이는 장치의 시뮬레이션 속도가 바뀐다. |
| 오디오 | BGM 음량 | 구현 | BGM 재생 음량만 바뀐다. |
| 오디오 | 효과음 음량 | 구현 | 효과음 음량과 스피커 음파의 밀어내기 세기가 함께 바뀐다. |
| 시스템 | BRICK 충돌 | 구현·확정 | BRICK WALL의 플레이어 충돌이 ON/OFF로 바뀐다. |

중력 방향은 물리 처리 기반은 있지만 SETTINGS 항목에서 현재 비노출 상태다. 따라서 아래 내용은 향후 후보이며, 현재 ROOM 풀이의 전제로 삼지 않는다.

## 시스템: BRICK 충돌

상태: 확정

설정 형태: `BRICK 충돌 ON/OFF`

기본 작동 원리:

BRICK WALL로 분류된 월드 오브젝트의 충돌 여부를 설정에서 변경한다. 충돌이 ON이면 벽이나 장애물로 작동하고, OFF이면 플레이어가 통과할 수 있다.

이 기믹은 초반부에서 플레이어에게 "설정 변경이 실제 월드에 영향을 준다"는 핵심 규칙을 학습시키는 대표 기믹이다.

레벨 설계 기준:

- 충돌 ON 상태에서는 막힌 길로 명확히 보이게 한다.
- 충돌 OFF 상태에서는 통과 가능해진 변화가 즉시 이해되어야 한다.
- 첫 학습 구간에서는 다른 설정과 섞지 않는다.

## 시스템: 중력 방향

상태: 후보 (현재 SETTINGS UI 비노출)

설정 후보: `↓ / ← / ↑ / →`

기존의 단순한 `중력 ON/OFF`보다 중력 방향을 변경하는 방식으로 설계한다. 화면 자체가 회전하는 것이 아니라 게임 월드의 중력 방향이 변경된다.

기본 작동 원리:

- 중력 방향에 따라 플레이어의 낙하 방향이 바뀐다.
- 기존의 벽이나 천장이 새로운 바닥 역할을 할 수 있다.
- 낙하 방향을 이용해 기존에는 접근할 수 없던 공간으로 이동하는 퍼즐을 만든다.

검토 사항:

- 중력 세기를 단계별로 변경하는 방식도 후보지만 현재는 방향 변경을 우선 검토한다.
- 방향 전환 시 조작 감각, 충돌 처리, 카메라 처리의 UX 검증이 필요하다.

## 오디오: 음량 / 음파

상태: 프로토타입 구현

현재 설정값: `0%`부터 `100%`까지 10% 단위

스테이지에 스피커 또는 소리를 발생시키는 오브젝트가 존재한다. 해당 오브젝트는 지속적으로 음파를 발생시키며 영향 범위 안의 이동 가능한 대상을 밀어낸다.

스피커 오브젝트 자체의 공통 범위·배치 규칙은 [스피커와 음파](speaker.md)를 따른다.

기본 작동 원리:

- 높은 효과음 음량에서는 음파가 강해 범위 안의 이동 가능한 대상이 크게 밀린다.
- 효과음 음량을 낮추면 음파의 밀어내는 힘이 감소해 통과할 수 있다. BGM 음량은 월드 물리에 영향을 주지 않는다.
- 마우스 슬라이더는 사용하지 않는다.

남은 확인:

- 음파의 시각 표현과 실제 밀어내는 범위가 어긋나지 않아야 한다.

## 게임: 캐릭터 유연성

상태: 프로토타입 검증 중

설정값: `단단함 / 보통 / 말랑함`

현재 플레이어 캐릭터의 말랑하고 찌그러지는 움직임을 단순한 시각 연출에서 실제 게임 설정으로 확장하는 아이디어다.

### 현재 프로토타입 규칙

- 보통·단단함의 충돌 크기는 `40x40px`다.
- 말랑함의 지상 충돌 크기는 진행 축 `46.4px`, 중력 축 `30px`다. 높이 30px 통로를 통과한다.
- 말랑함의 공중 충돌 크기는 진행 축 `39.2px`, 중력 축 `41.6px`다.
- 기본 자세의 충돌 크기는 아래 시각 표현의 목표 크기와 같다. 점프·착지 중 짧은 탄성만 별도 시각 연출로 남긴다.

### 시각 표현

- 말랑함은 지상에서 가로 1.16배·세로 0.80배(46.4×30px), 공중에서 가로 0.98배·세로 1.04배(39.2×41.6px)를 목표로 하며, 기본 충돌 크기도 같은 값으로 맞춘다.
- 점프·착지 반응은 이 범위 안에서 짧게 탄성만 보이며, 충돌 크기 그대로 길게 늘어지거나 처져 보이지 않아야 한다.

미확정:

- 단단함과 보통의 차별화된 장점
- 최종 충돌 수치와 상태별 상호작용 범위
- 최종 변형 표현과 판정의 세부 조정


## 게임: 기믹 속도

상태: 프로토타입 구현

설정값: `느림 / 보통 / 빠름`

현재 배율은 각각 `0.55 / 1.0 / 1.35`다. 움직이는 월드 오브젝트와 장치의 시뮬레이션 시간에 적용하며, 피스톤의 `1.10초` 공통 주기 진행 속도에도 같은 배율을 사용한다.

기본 작동 원리 후보:

- 음수 속도
- 0%
- 정상 속도
- 비정상적으로 빠른 속도

검토 사항:

- 음수 속도를 게임 전체의 완전한 시간 역행으로 구현하는 것은 복잡도가 매우 높으므로 확정하지 않는다.
- 필요하다면 특정 시간 종속 오브젝트만 역방향으로 작동하는 방식을 검토한다.
- 정상 범위를 벗어난 값은 후반부 확장 아이디어로 둔다.

## UI 자체를 이용한 퍼즐

상태: 장기 후보

게임 월드뿐 아니라 UI나 설정 메뉴 자체를 퍼즐의 일부로 사용하는 아이디어다.

기본 작동 원리 후보:

현재는 구체적인 규칙이 없으므로 후반부 또는 메타 기믹 후보로만 기록한다.

미확정:

- UI 요소가 월드와 상호작용하는 방식
- 설정 메뉴의 위치, 선택 상태, 카테고리 구조를 퍼즐 규칙으로 사용할지 여부
- 플레이어가 불합리하게 느끼지 않도록 하는 제약
