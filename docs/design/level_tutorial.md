# 레벨과 튜토리얼

## 전체 진행 방향

현재 진행 구조는 최종 스테이지 구성이 아니라 전체 방향으로만 둔다.

- 초반: 설정 하나가 월드에 직접 영향을 준다는 개념을 학습한다.
- 중반: 물리뿐 아니라 오디오 같은 일반적인 게임 설정까지 퍼즐에 사용한다.
- 후반: 기존 설정의 예상하지 못한 활용, 설정 간 조합, 비정상적인 설정값이나 UI 자체를 활용하는 메타적인 퍼즐을 검토한다.

## 레벨 설계 원칙

- 한 레벨은 가능하면 하나의 핵심 질문만 던진다.
- 새 설정은 독립된 안전한 환경에서 먼저 학습시킨다.
- 학습 직후에는 같은 설정을 약간 다른 맥락에서 다시 사용하게 한다.
- 여러 설정 조합은 플레이어가 각 설정을 충분히 이해한 뒤에 사용한다.
- 실패 이유가 설정값 때문인지 조작 실수 때문인지 구분 가능해야 한다.
- 설정 변경 결과는 즉각적이고 시각적으로 읽혀야 한다.
- 수치 맞추기, 암기, 숨은 정답 찾기가 핵심 퍼즐이 되지 않게 한다.

## 튜토리얼 설계 원칙

- 설명문보다 관찰과 실험을 우선한다.
- 설정 메뉴를 열어야 하는 상황은 월드 구조로 자연스럽게 만든다.
- 첫 설정 기믹은 `BRICK 충돌`을 우선 사용한다.
- 초반 튜토리얼에서는 설정 UI 조작과 월드 변화가 같은 화면 흐름 안에서 이어져야 한다.
- 설정을 바꾼 뒤 바로 통과, 낙하, 밀림 감소처럼 결과를 체감하게 한다.

## 초반 학습 흐름 후보

이 흐름은 확정된 스테이지 목록이 아니라 설계 방향이다.

1. 기본 이동과 EXIT 도달을 학습한다.
2. 설정 UI를 여는 법과 키보드 선택 방식을 학습한다.
3. `BRICK 충돌`을 OFF로 바꿔 막힌 길을 통과한다.
4. `BRICK 충돌`을 다시 ON/OFF로 비교하며 설정과 월드의 연결을 확실히 이해한다.
5. 이후 중력 방향, 음량/음파 등 다른 카테고리의 설정으로 확장한다.

## 조합 레벨 원칙

- 조합 레벨은 "두 설정을 모두 알아야 한다"는 점이 명확해야 한다.
- 조합 자체가 복잡한 메뉴 조작 순서 암기가 되지 않게 한다.
- 가능한 경우 각 설정의 변화가 서로 다른 시각 피드백을 갖도록 한다.
- 하나의 설정만 잘못 바꿨을 때도 왜 실패했는지 관찰 가능해야 한다.

## 현재 구현과의 구분

현재 프로토타입은 제한된 방과 일부 설정 항목만 가진 검증용 빌드다. 이 문서의 진행 구조와 후보 기믹은 목표 기획이며, 현재 구현 완료 범위로 해석하지 않는다.
