# 확정 사항과 미확정 사항

## 현재 확정 사항

- 게임은 설정 메뉴의 값을 변경해 스테이지의 규칙과 상태를 조작하는 미니멀 퍼즐 게임이다.
- 단순 기능 제거는 더 이상 핵심 게임 콘셉트가 아니다.
- 설정 UI는 키보드만으로 조작한다.
- 설정값은 ON/OFF 또는 명확한 단계/선택지 위주로 설계한다.
- 현재 기준 설정 카테고리는 `게임`, `오디오`, `화면`, `시스템`이다.
- 카테고리 구조는 향후 변경될 수 있다.
- `BRICK 충돌 ON/OFF`는 확정 기믹이다.
- 초반에는 `BRICK 충돌`로 설정 변경이 월드에 영향을 준다는 핵심 규칙을 학습시킨다.
- 미니멀 도형 기반 비주얼, 어두운 배경, 얇은 선, Red 계열 중심의 제한 팔레트 방향을 유지한다.
- 현재 인게임 컬러 테스트 기준은 `Red Platform` 팔레트다. 일반 플랫폼을 Main Red 계열 단색 면으로 두고, BRICK WALL은 같은 Hue의 명도/채도 variation으로 특정 기믹 전용 Red 의미를 만들지 않는다.
- SETTINGS UI는 현재 `1120x632` 중앙 2열 패널, CATEGORY/SETTING 구조, Cyan 포커스 표현을 기준으로 구현되어 있다. 최종 확정 전 실제 게임 화면 위 가독성 캡처가 필요하다.

## 유력 방향

- 중력은 단순 ON/OFF보다 `↓ / ← / ↑ / →` 방향 변경을 우선 검토한다.
- 오디오 음량은 스피커/음파 오브젝트의 밀어내는 힘 또는 범위와 연결하는 방향을 우선 검토한다.
- 음량 조작은 연속 슬라이더가 아니라 소수의 명확한 단계로 설계한다.

## 검토 중인 기믹

- 게임: 캐릭터 유연성
- 화면: 해상도 / 화면비
- 게임: 게임 속도
- UI 자체를 이용한 퍼즐

## 아직 확정하지 않는 사항

- 중력 방향의 최종 상태 수와 세부 조작 방식
- 중력 세기 변경 여부
- 음량 단계의 정확한 수치와 단계 수
- 캐릭터 유연성의 충돌 판정과 물리적 장단점
- 해상도/화면비 변경을 실제 창 크기 변경으로 구현할지 내부 viewport 변경으로 구현할지
- 게임 속도에서 음수 속도나 비정상 속도를 어떤 범위까지 허용할지
- UI 자체를 퍼즐 요소로 사용할 구체 규칙
- 최종 스테이지 수와 진행 순서
- 현재 Red Platform 팔레트의 최종 확정 여부와 후속 보정 범위
- SETTINGS UI 수치와 가독성의 최종 확정 여부

## 향후 설계가 필요한 항목

- 각 설정 항목의 최종 명칭과 UI 표기
- 설정별 상태 수와 입력 방식
- 각 기믹의 첫 학습 레벨
- 설정 조합 레벨의 도입 시점
- 기믹별 시각 피드백 규칙
- 실패 및 리셋 UX
- 해상도, 화면비처럼 UX 리스크가 큰 후보의 검증 프로토타입
- Red Platform 팔레트의 추가 ROOM/기믹 적용 검증
- 현재 코드의 내부 명칭인 `DeleteFeature`, `DeleteState`를 최신 기획에 맞춰 바꿀지 여부
