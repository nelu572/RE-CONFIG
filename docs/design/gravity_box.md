# 중력 박스

## 문서 범위

이 문서는 모든 ROOM에서 공통으로 쓰는 중력 박스의 기본 크기와 배치 규칙을 정의한다. ROOM 문서는 박스의 시작 위치와 퍼즐에서 맡는 역할만 기록한다.

## 공통 크기

- 중력 박스의 충돌·렌더 크기는 항상 `1.5T x 1.5T`다.
- ROOM별 크기 예외는 두지 않는다.
- ROOM은 박스의 시작 좌표만 정한다.

## 맵 표기

- ASCII의 `B`는 박스 시작 배치 예약 영역이다.
- `B` 영역 안에 `Q`가 없으면 박스는 그 영역의 중심에 배치한다.
- `Q`가 있으면 `Q` 타일 중심을 박스 중심으로 사용한다.
- 자세한 타일 표기 규칙은 [ROOM 맵 가이드](../rooms/ROOM_MAP_GUIDE.md)를 따른다.
