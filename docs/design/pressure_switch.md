# 압력 스위치와 이동 문

## 문서 범위

이 문서는 압력 스위치와 연결된 이동 문/플랫폼의 공통 상호작용을 정의한다. ROOM 문서는 스위치가 어느 경로를 열고, 어떤 오브젝트를 어느 위치에 유지시켜야 하는지만 기록한다.

## 압력 스위치

- 기본 activator는 `PRESSURE_SWITCH_ANY`다.
- ANY 스위치는 플레이어, 중력 박스, 피스톤 플레이트가 모두 누를 수 있다.
- 박스 전용 또는 적 전용처럼 기본 activator를 바꾸는 경우는 ROOM별 예외다. 변경 이유와 퍼즐 영향을 해당 ROOM에 기록한다.
- 바닥형 스위치의 기본 크기는 `2T x 1T`다. 세로 벽형 스위치는 `1T x 2T`로 둔다. 이 두 크기는 ROOM 맵에서 차지하는 타일 그대로 표현한다.
- 바닥 매립형 스위치는 스위치 면적만 표면에서 비우고, 바로 아래부터는 일반 바닥으로 채운다. 고정 바닥 충돌체와 스위치 충돌체를 겹치지 않는다.
- `MOUNT_AUTO` 스위치는 접한 일반 고정 플랫폼 또는 닫힌 상태의 이동 문/플랫폼 변 가운데 겹치는 길이가 가장 긴 면에 부착한다. 길이가 같으면 아래, 오른쪽, 왼쪽, 위 순서로 선택한다. 이 장착면은 문/플랫폼이 움직여도 바뀌지 않으며, 충돌 판정과 시각 표현이 같은 면을 사용한다.
- 어떤 일반 고정 플랫폼 또는 닫힌 상태의 이동 문/플랫폼에도 닿지 않은 공중 스위치는 가로형은 아래, 세로형은 오른쪽을 기본 장착 방향으로 쓴다.

## 연결 문·플랫폼

- 스위치가 한 번이라도 눌리면 연결된 문/플랫폼은 열림 목표 위치까지 반드시 한 번 이동한다. 도중에 스위치가 해제되어도 중간에서 반전하지 않는다.
- 문/플랫폼이 열림 목표 위치에 도달했을 때 스위치가 해제된 상태라면 닫힌 위치로 돌아간다. 계속 눌린 상태라면 열린 위치를 유지한다.
- 문/플랫폼은 이동 거리와 무관한 고정 시간 대신 일정한 물리 속도로 움직인다. 열림·닫힘 모두 `560px/s`이며, 게임 속도 설정이 이 진행 속도에 적용된다.
- 플레이어가 플랫폼의 중력 방향 표면에 탑승한 상태여도 플랫폼은 멈추지 않고, 플레이어는 해당 프레임의 플랫폼 이동량만큼 함께 이동한다.
- 어떤 스위치가 어떤 문을 열고, 열렸을 때 경로가 어떻게 달라지는지는 ROOM 문서가 소유한다.
- `T`, `H`, `V`, `h`, `v`, 연결 ID의 ASCII 표기는 [ROOM 맵 가이드](../rooms/ROOM_MAP_GUIDE.md)를 따른다.

## 압력 장벽

- X 장벽은 연결된 스위치가 한 번이라도 눌리면 같은 위치에서 알파 1에서 0까지 페이드아웃을 완료한다. 도중에 스위치가 해제되었으면 알파 0에 도달한 뒤 1까지 페이드인한다.
- X 장벽은 알파가 정확히 1인 완전 불투명 상태에서만 충돌한다. 페이드아웃이 시작되어 알파가 1보다 작아지는 순간부터 비충돌이며, 페이드인이 끝나 알파가 1에 도달한 뒤에만 충돌이 복구된다.
- 기본 이동형 적도 플레이어·중력 박스와 같은 알파 기준으로 X 장벽과 충돌한다.
- 플레이어나 중력 박스가 X 장벽 영역과 겹쳐 있으면 페이드인 완료와 충돌 복구를 보류한다.
