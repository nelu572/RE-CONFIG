# 피스톤

## 문서 범위

이 문서는 피스톤의 공통 시간·물리 상호작용을 정의한다. ROOM 문서는 피스톤이 어느 구간을 가로지르고, 이동수단·위협·공간 제약 중 어떤 역할을 맡는지만 기록한다.

## 공통 규칙

- 피스톤은 travel과 무관한 공통 주기를 사용하지 않는다. 확장은 `30T/초`, 수축은 `12T/초`의 공통 선속도로 움직이므로, travel이 길수록 이동 시간도 길어진다.
- 확장 전 `0.154초`, 완전 확장 후 `0.110초`, 수축 후 `0.132초` 동안 정지한다.
- ROOM별 시작 지연은 ROOM 진입 직후 처음 확장을 늦추는 초 단위 값이다. 이후에는 각 피스톤의 travel로 계산한 고유 왕복 주기를 반복한다.
- SETTINGS의 `기믹 속도` 배율을 피스톤의 시간 진행에 적용한다. `느림`은 `0.55배`, `보통`은 `1.0배`, `빠름`은 `1.35배`다.
- 피스톤 본체, 샤프트, 플레이트는 충돌체다. 이동 중에는 플레이어와 중력 박스를 밀거나 플레이트 위에 실어 나를 수 있다.
- 수평 피스톤의 누르는 판과 본체 높이는 ROOM에 지정된 폭을 그대로 사용한다. 연결 샤프트는 5T 판에서 약 1T인 두께를 기준으로 비례 축소하므로, 판이 1T이면 샤프트는 기준의 20% 두께가 된다. 내부 강조선도 같은 비율을 사용하며 렌더링과 충돌은 같은 크기를 사용한다.
- 피스톤은 어려운 타이밍 수행을 강요하는 핵심 퍼즐이 아니라 이동수단, 박스 위협, 공간 제약으로 사용한다.

## ROOM별로 정하는 항목

- 방향, 수축·확장 위치, travel, 시작 지연 시간(초)
- 본체·샤프트·플레이트의 실제 크기
- 다른 오브젝트와의 sweep 관계와 그로 인해 생기는 경로 판단

`I/i`의 ASCII 표기와 sweep 읽기 규칙은 [ROOM 맵 가이드](../rooms/ROOM_MAP_GUIDE.md)를 따른다.
