# 피스톤

## 문서 범위

이 문서는 피스톤의 공통 시간·물리 상호작용을 정의한다. ROOM 문서는 피스톤이 어느 구간을 가로지르고, 이동수단·위협·공간 제약 중 어떤 역할을 맡는지만 기록한다.

## 공통 규칙

- 모든 피스톤은 전역 공통 주기 `1.10초`를 사용한다. ROOM별 주기값은 만들지 않는다.
- 피스톤 본체, 샤프트, 플레이트는 충돌체다. 이동 중에는 플레이어와 중력 박스를 밀거나 플레이트 위에 실어 나를 수 있다.
- 피스톤은 어려운 타이밍 수행을 강요하는 핵심 퍼즐이 아니라 이동수단, 박스 위협, 공간 제약으로 사용한다.

## ROOM별로 정하는 항목

- 방향, 수축·확장 위치, travel, phase
- 본체·샤프트·플레이트의 실제 크기
- 다른 오브젝트와의 sweep 관계와 그로 인해 생기는 경로 판단

`I/i`의 ASCII 표기와 sweep 읽기 규칙은 [ROOM 맵 가이드](../rooms/ROOM_MAP_GUIDE.md)를 따른다.
