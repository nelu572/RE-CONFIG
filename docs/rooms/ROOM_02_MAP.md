# ROOM 02 Map Draft

## 목적

이 파일은 ROOM 02의 현재 코드 맵을 문서로 옮긴 60x27 타일맵 초안이다.
사용자가 이 맵을 수정하면, 이후 src/game/rooms/room02.cpp를 이 타일맵 기준으로 반영한다.

ROOM 02는 스피커 음량 / 음파 기믹을 확인하는 방이다. 오른쪽에 있는 스피커의 영향을 받으며 EXIT에 접근한다.

## 맵 규격

- 전체 프레임: **60T x 27T**
- 1T = 40px
- 각 행은 반드시 60글자여야 한다.
- 전체 행 수는 반드시 27행이어야 한다.
- 빈 공간은 .으로 적는다.
- 화면 밖이나 사용하지 않는 공간도 맵 안에서는 #로 채운다.

## 범례

- # : 일반 벽 / 고정 플랫폼
- . : 플레이 가능한 빈 공간
- P : 플레이어 시작 위치
- K : 스피커 본체 영역
- E : EXIT 배치 예약 영역

## 스피커 표기 방식

스피커는 실제 크기감을 보기 위해 K를 여러 칸으로 채워 표시한다.
이 초안에서 K 영역은 5T x 9T 스피커 본체를 뜻한다.

음파는 별도 타일로 표시하지 않는다. 스피커는 360도 범위로 영향을 주므로, 맵에서는 K와 다른 오브젝트의 상대 위치만 보고 판단한다.

## 의도한 풀이

1. 플레이어는 오른쪽 EXIT 방향으로 이동한다.
2. K 스피커의 음파가 이동을 방해하면 효과음 음량을 낮춘다.
3. 밀림이 줄어든 상태에서 E EXIT에 들어간다.

## 코드 반영 메모

- 연속된 #는 가능한 한 큰 RectF 플랫폼으로 병합한다.
- P, K, E는 플랫폼이 아니라 오브젝트 배치 마커로 처리한다.
- K는 SpeakerDevice로 만든다.
- E는 RoomDef.exit로 만든다.
- 음파는 맵에 타일로 표시하지 않는다.
