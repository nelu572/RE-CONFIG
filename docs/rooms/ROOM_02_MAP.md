# ROOM 02 Map Draft

## 목적

이 파일은 ROOM 02의 현재 코드 맵을 문서로 옮긴 48x27 타일맵 초안이다.
사용자가 이 맵을 수정하면, 이후 src/game/rooms/room02.cpp를 이 타일맵 기준으로 반영한다.

ROOM 02는 BRICK WALL / TYPE A 벽의 충돌 설정을 이용해 중앙 벽을 통과하는 방이다.

## 맵 규격

- 전체 프레임: **48T x 27T**
- 각 행은 반드시 48글자여야 한다.
- 전체 행 수는 반드시 27행이어야 한다.
- 공통 규격, 범례, 작성 원칙은 [ROOM_MAP_GUIDE.md](ROOM_MAP_GUIDE.md)를 따른다.

## 사용 오브젝트

- `#`, `.`, `P`, `A`, `E`

## 방별 오브젝트 메모

- A는 현재 코드의 `type_a_walls`에 해당한다.
- TYPE A는 기존 벽돌 오브젝트이며 외형을 변경하지 않는다.

## 의도한 풀이

1. 플레이어는 중앙의 A 벽 때문에 EXIT 방향으로 바로 이동할 수 없다.
2. BRICK 충돌을 OFF로 바꾸면 A 벽을 통과할 수 있다.
3. 오른쪽의 E EXIT에 들어간다.
