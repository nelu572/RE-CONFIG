# ROOM 09 Map Draft

## 상태

**미설계.** 현재 ROOM 09는 후반부용 큰 플랫포밍 스테이지를 설계하기 전, 시스템 확인에만 쓰는 중립 임시룸이다. 이 맵의 크기와 형태는 최종 ROOM 09 디자인이 아니다.

현재 목적은 `진입 → 이동 → EXIT → 클리어` 경로와 기본 카메라/전환을 확인하는 것이다. BRICK, 피스톤, 스피커, 박스, 스위치, 특수 플랫폼은 배치하지 않는다. 단, 이동형 적 런타임 확인을 위해 M 하나만 임시 배치한다.

## 맵 규격

- 전체 프레임: **32T x 18T**
- 각 행: 32글자
- 전체 행: 18행
- 공통 규격은 [ROOM_MAP_GUIDE.md](ROOM_MAP_GUIDE.md)를 따른다.

## 구현 메모

- 플레이어 시작은 `(3T, 15T)`이며, 일반 바닥은 `y=16T`부터다.
- EXIT는 `(27T, 14T, 2T, 2T)`다.
- M은 `(15T, 15.1T, 1.5T, 0.9T)`, 속도 `120px/s`, 초기 왼쪽 이동인 임시 `WalkerEnemyDef`다. 평소 실루엣은 폭 1.5T·높이 36px의 낮고 넓은 빨간 반원이며 바닥면은 평평하다. 플레이어가 2.5T 안에 들어오면 즉시 순찰을 멈추고 바닥을 고정한 채 높이 약 83%·폭 약 108%로 웅크린 뒤 0.045초에 현재 body 외곽선부터 tip까지 16px 길이·같은 두께로 배치된 상단 메인 삼각형 가시 5개와, 바닥선에 수평 절단면을 붙인 양쪽 반 잘린 직각 쐐기형 보조 가시 2개가 body에서 직접 뻗는다. 플레이어가 3T 밖으로 벗어나면 0.32초에 걸쳐 가시와 몸 높이를 함께 복원하고, 완전히 복원된 뒤 기존 방향 순찰을 재개한다. 수납 중 재접근하면 즉시 다시 최대 전개한다. 충돌 판정은 가시 상태와 무관하게 동일하다. 최종 ROOM 09 설계 전 제거하거나 새 배치로 대체한다.
- 최종 ROOM 09는 이후 기존 ROOM보다 큰 규모의 플랫포밍 스테이지로 별도 설계한다.
