# ROOM 01 Map Draft

## 목적

이 파일은 ROOM 01의 현재 코드 맵을 문서로 옮긴 48x27 타일맵 초안이다.
사용자가 이 맵을 수정하면, 이후 src/game/rooms/room01.cpp를 이 타일맵 기준으로 반영한다.

ROOM 01은 BRICK WALL / TYPE A 벽의 충돌 설정을 이용해 중앙 벽을 통과하는 방이다.

## 맵 규격

- 전체 프레임: **48T x 27T**
- 1T = 40px
- 각 행은 반드시 48글자여야 한다.
- 전체 행 수는 반드시 27행이어야 한다.
- 빈 공간은 .으로 적는다.
- 화면 밖이나 사용하지 않는 공간도 맵 안에서는 #로 채운다.

## 범례

- # : 일반 벽 / 고정 플랫폼
- . : 플레이 가능한 빈 공간
- P : 플레이어 시작 위치
- A : BRICK WALL / TYPE A 벽
- E : EXIT 배치 예약 영역

## BRICK WALL 표기 방식

A는 현재 코드의 type_a_walls에 해당한다.
TYPE A는 기존 벽돌 오브젝트이며 외형을 변경하지 않는다.

## 의도한 풀이

1. 플레이어는 중앙의 A 벽 때문에 EXIT 방향으로 바로 이동할 수 없다.
2. BRICK 충돌을 OFF로 바꾸면 A 벽을 통과할 수 있다.
3. 오른쪽의 E EXIT에 들어간다.

## 코드 반영 메모

- 연속된 #는 가능한 한 큰 RectF 플랫폼으로 병합한다.
- A, P, E는 플랫폼이 아니라 오브젝트 배치 마커로 처리한다.
- A는 type_a_walls로 만든다.
- E는 RoomDef.exit로 만든다.
- TYPE A는 기존 벽돌 오브젝트이며 외형을 변경하지 않는다.
