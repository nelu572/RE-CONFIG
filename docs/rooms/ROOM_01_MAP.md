# ROOM 01 Map Draft

## 목적

이 파일은 ROOM 01의 현재 코드 맵을 문서로 옮긴 48x27 타일맵 초안이다.
사용자가 이 맵을 수정하면, 이후 src/game/rooms/room01.cpp를 이 타일맵 기준으로 반영한다.

ROOM 01은 기본 이동과 EXIT 도달을 확인하는 첫 방이다. 별도 기믹 없이 바닥 플랫폼 위에서 오른쪽 EXIT로 이동한다.

## 맵 규격

- 전체 프레임: **48T x 27T**
- 각 행은 반드시 48글자여야 한다.
- 전체 행 수는 반드시 27행이어야 한다.
- 공통 규격, 범례, 작성 원칙은 [ROOM_MAP_GUIDE.md](ROOM_MAP_GUIDE.md)를 따른다.

## 사용 오브젝트

- `#`, `.`, `P`, `E`
