# ROOM 07 Map Draft

## 목적

ROOM 07은 BRICK 충돌 설정과 피스톤 타이밍 점프를 함께 쓰는 대규모 실제 플레이 후보 맵이다.
플레이어는 TYPE A 벽돌을 OFF로 만들어 초반 게이트를 통과하고, 다시 ON으로 만들어 중반 발판을 사용한 뒤, 상승 피스톤을 타고 상단 라인으로 올라간다.
후반에는 BRICK 충돌을 다시 OFF로 바꿔 상단 셔터를 통과하고, 피스톤 타이밍을 보며 EXIT에 들어간다.

중력 방향 변경, 새 SETTINGS 항목, 박스, 스위치, 문은 사용하지 않는다.

## 맵 규격

- 전체 프레임: **96T x 27T**
- 각 행은 반드시 96글자여야 한다.
- 전체 행 수는 반드시 27행이어야 한다.
- 공통 규격, 범례, 작성 원칙은 [ROOM_MAP_GUIDE.md](ROOM_MAP_GUIDE.md)를 따른다.

## 사용 오브젝트

- `#`, `.`, `P`, `E`, `A`, `I`, `i`

## 방별 오브젝트 메모

- A 게이트는 `(13T, 21T, 2T, 4T)`이다. BRICK 충돌이 켜져 있으면 막히고, 꺼져 있으면 통과한다.
- A 발판은 `(42T, 22T, 8T, 1T)`이다. BRICK 충돌을 다시 켜야 발판으로 밟고 고정 벽을 넘을 수 있다.
- A 셔터는 `(86T, 14T, 2T, 4T)`이다. 상단 복도에서 BRICK 충돌을 다시 꺼야 통과할 수 있다.
- 고정 발판은 `(31T, 23T, 8T, 2T)`, `(53T, 22T, 7T, 1T)`, `(72T, 19T, 5T, 1T)`, `(78T, 18T, 15T, 1T)`이다.
- 고정 벽은 `(50T, 22T, 3T, 3T)`이다.
- 첫 번째 피스톤은 `PISTON_DOWN`, body `(22T, 8T)`, travel `15T`, cycle_seconds `1.18s`, phase `0.00`이다.
- 두 번째 피스톤은 `PISTON_DOWN`, body `(60T, 5T)`, travel `16T`, cycle_seconds `1.28s`, phase `0.22`이다.
- 세 번째 피스톤은 `PISTON_DOWN`, body `(75T, 3T)`, travel `14T`, cycle_seconds `1.45s`, phase `0.55`이다.
- 네 번째 피스톤은 `PISTON_LEFT`, body `(91T, 13T)`, travel `10T`, cycle_seconds `1.35s`, phase `0.15`이다.
- 다섯 번째 피스톤은 `PISTON_UP`, body `(66T, 24T)`, travel `4T`, cycle_seconds `1.55s`, phase `0.35`이다. 수축 상태 플레이트는 낮은 대기 발판이고, 완전 확장 상태 플레이트는 상단 발판과 같은 높이다. 기믹 속도를 빠름으로 올리면 플레이어에게 전달되는 상승 속도도 더 강해진다.
- 모든 피스톤은 기본 폭 5T, body_height 1T, shaft_width 0.90T, plate_height 1T를 사용한다.
- `I`는 수축 상태 플레이트 위치, `i`는 완전 확장 상태 플레이트 위치다.
- EXIT는 `(89T, 16T, 2T, 2T)`이다.
- 플레이어 시작 위치는 `(6T, 24T)`이다.

## 의도한 풀이

1. 시작 지점에서 오른쪽으로 이동해 A 게이트가 BRICK 충돌에 막히는 것을 확인한다.
2. 기존 SETTINGS의 BRICK 충돌을 OFF로 바꿔 A 게이트를 통과한다.
3. 첫 번째 하강 피스톤이 올라간 타이밍에 지상 구간을 통과하고, 오른쪽 낮은 발판으로 올라간다.
4. 고정 벽 앞에서 BRICK 충돌을 ON으로 되돌려 A 발판을 만든다.
5. A 발판을 밟고 고정 벽을 넘어 두 번째 하강 피스톤 사이의 중단 발판으로 점프한다.
6. 상승 피스톤의 낮은 플레이트에 올라타고, 필요하면 기믹 속도를 빠름으로 올려 상승 속도를 크게 만든 뒤 오른쪽 상단 발판으로 점프한다.
7. 세 번째 하강 피스톤 타이밍을 보고 상단 복도에서 전진한다.
8. 상단 A 셔터 앞에서 BRICK 충돌을 OFF로 바꾸고, 좌향 피스톤의 왕복 타이밍을 보고 지나간다.
9. 오른쪽 상단 EXIT에 들어가 클리어한다.

## 코드 반영 메모

- A는 `type_a_walls`로 만든다.
- I/i는 `PistonDevice`로 만든다.
- 상승 피스톤은 새 물리 없이 기존 `PISTON_UP` 방향을 사용한다.
- 박스, 스위치, 압력 플랫폼, 스피커는 ROOM 07 후보 맵에서 사용하지 않는다.
- 새 SETTINGS 항목은 추가하지 않는다.
- 중력 방향 변경 기믹은 사용하지 않는다.
