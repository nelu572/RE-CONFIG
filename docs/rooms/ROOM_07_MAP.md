# ROOM 07 Map Draft

## 목적

이 파일은 ROOM 07의 확장 설계 초안인 101x43 타일맵이다.
플랫폼 사이의 가로 간격과 이동 폭을 넓히고, 중간 순환 경로의 세로 여유를 크게 둔다. 기존 오브젝트의 종류와 크기는 유지한다.

ROOM 07은 스피커, 박스, 스위치, 정적 가시를 조합하는 방이다. 박스를 움직이는 동안에는 스피커가 플레이어를 EXIT 반대 방향으로 밀고, 스위치가 눌린 뒤 음량을 낮춰야 가시 귀환로를 지나 EXIT에 들어갈 수 있다.

## 맵 규격

- 전체 프레임: **101T x 43T**
- 각 행은 반드시 101글자여야 한다.
- 전체 행 수는 반드시 43행이어야 한다.
- 공통 규격, 범례, 작성 원칙은 [ROOM_MAP_GUIDE.md](ROOM_MAP_GUIDE.md)를 따른다.

## 사용 오브젝트

- `#`, `.`, `P`, `B`, `K`, `T`, `H`, `h`, `V`, `E`, `M`, `N`, `1`

## 방별 오브젝트 메모

- K의 공통 음파 규칙은 [스피커와 음파](../design/speaker.md)를 따른다.
- `1T`는 두 `1XX` 장벽을 없애는 T1 스위치다. 공통 스위치 규칙은 [압력 스위치와 이동 문](../design/pressure_switch.md)을 따른다.


- 오른쪽 확장부의 귀환로에는 바닥 가시 `M` 두 개와 천장 가시 `N` 한 개를 교차 배치한다. 공통 가시 규칙은 [정적 가시](../design/static_spike.md)를 따른다.
- 가시 귀환로는 스피커를 낮춘 뒤에만 안정적으로 왼쪽 EXIT 방향으로 이동할 수 있는 폭으로 둔다. 가시는 박스를 밀거나 스위치를 누르는 수단이 아니다.

- 확장 초안의 연결 경로는 ASCII의 `1H`와 `1V`를 기준으로 읽는다. 기존 코드 반영 메모의 `X` 표기는 현재 코드 배치와 맞지 않아 사용하지 않는다.

## 의도한 풀이

1. 플레이어는 우측 계단을 올라가 스위치와 연결된 경로까지 갈 수 있지만, 닫힌 장벽 때문에 EXIT로 돌아갈 수 없다.
2. K 스피커의 음량을 올리면 상단 레일의 B 박스가 오른쪽으로 밀려 T1 스위치를 누른다.
3. 연결 장벽이 열리면 오른쪽 확장부의 가시 귀환로가 드러난다. 음량이 높은 상태에서는 반동 때문에 이 구간을 안정적으로 왼쪽으로 통과하기 어렵다.
4. 음량을 낮추면 박스는 T1에 남아 장벽이 열린 상태를 유지한다.
5. 플레이어는 바닥 가시와 천장 가시를 번갈아 피해 왼쪽의 E EXIT로 이동한다.

## 코드 반영 메모

- K, B, T, H/h, V, M, N의 변환은 [ROOM 맵 가이드](ROOM_MAP_GUIDE.md)를 따른다.
- 연결 장벽은 T1이 눌린 동안 열려, 스피커를 끈 뒤 가시 귀환로와 EXIT로 이어지는 경로를 만든다.
- 이 문서는 확장 설계 초안이므로, 코드 갱신 전에는 정적 가시의 실제 충돌 배치와 가시 사이 통과 폭을 현재 플레이어 충돌 크기로 대조한다.
