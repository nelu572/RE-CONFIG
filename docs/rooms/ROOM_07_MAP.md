# ROOM 07 Map Draft

## 목적

이 파일은 ROOM 07의 현재 임시 플레이테스트 코드를 문서로 옮긴 48x27 타일맵 초안이다.
최종 ROOM 07 설계가 아니라, 박스가 피스톤을 물리적으로 막는지 확인하기 위한 기믹 검증용 맵이다.

ROOM 07 임시 버전은 박스를 아래 방향 피스톤 sweep 안으로 밀어 넣고, 피스톤이 박스 상단에서 멈추면서 생기는 통과 공간을 이용해 EXIT로 이동하는 방이다.

## 맵 규격

- 전체 프레임: **48T x 27T**
- 각 행은 반드시 48글자여야 한다.
- 전체 행 수는 반드시 27행이어야 한다.
- 공통 규격, 범례, 작성 원칙은 [ROOM_MAP_GUIDE.md](ROOM_MAP_GUIDE.md)를 따른다.

## 사용 오브젝트

- `#`, `.`, `P`, `B`, `I`, `i`, `E`

## 방별 오브젝트 메모

- B는 2x2 예약 영역에 실제 1.5T x 1.5T 박스를 생성한다. 실제 배치는 `(14.25T, 21.5T)`를 사용한다.
- I/i는 공통 피스톤 시작-끝 표기를 사용한다.
- 피스톤은 기본 폭 5T, body_height 1T, shaft_width 0.90T, plate_height 1T를 사용한다.
- 피스톤은 `PISTON_DOWN`, travel 9T, cycle_seconds 1.18s, phase 0.00이다.
- i는 박스가 없을 때 피스톤 플레이트가 바닥까지 내려오는 최대 위치다.
- 박스를 I에서 i까지의 sweep 안으로 밀어 넣으면 피스톤은 박스 상단에서 멈춘다.
- 스위치, 문, 새 SETTINGS 항목은 이 임시 테스트룸에서 사용하지 않는다.

## 의도한 풀이

1. 플레이어는 피스톤이 바닥까지 내려와 통로를 막는 것을 확인한다.
2. 왼쪽의 B 박스를 오른쪽으로 몇 칸 밀어 피스톤 sweep 안에 넣는다.
3. 피스톤이 박스를 관통하거나 밀어내지 않고 박스 상단에서 멈추는 것을 확인한다.
4. 박스 옆에 남은 피스톤 아래 공간으로 지나간다.
5. 오른쪽의 E EXIT에 들어간다.

## 코드 반영 메모

- B는 `GravityBoxDef`로 만든다.
- I/i는 `PistonDevice`로 만든다.
- 피스톤은 박스를 강제로 밀지 않고, `PistonMaxExtensionBeforeRect`를 통해 박스 상단 직전에서 effective extension을 제한한다.
- 새 SETTINGS 항목은 추가하지 않는다.
- 중력 방향 변경 기믹은 사용하지 않는다.
