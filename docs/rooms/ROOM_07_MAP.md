# ROOM 07 Map Draft

## 목적

이 파일은 ROOM 07의 현재 임시 플레이테스트 코드를 문서로 옮긴 67x27 타일맵 초안이다.
최종 ROOM 07 설계가 아니라, 피스톤이 박스를 물리적으로 밀 수 있는지 확인하기 위한 기믹 검증용 맵이다.

ROOM 07 임시 버전은 좌향 피스톤 sweep 안에 Q 앵커 박스가 놓였을 때, 피스톤이 박스를 안정적으로 미는지 확인하는 기믹 검증용 방이다.

## 맵 규격

- 전체 프레임: **67T x 27T**
- 각 행은 반드시 67글자여야 한다.
- 전체 행 수는 반드시 27행이어야 한다.
- 공통 규격, 범례, 작성 원칙은 [ROOM_MAP_GUIDE.md](ROOM_MAP_GUIDE.md)를 따른다.

## 사용 오브젝트

- `#`, `.`, `P`, `B`, `Q`, `I`, `i`, `E`

## 방별 오브젝트 메모

- B는 2x2 예약 영역에 실제 1.5T x 1.5T 박스를 생성한다. Q 타일 중심 `(7.5T, 23.5T)`을 박스 중심으로 사용하므로 실제 배치는 `(6.75T, 22.75T)`를 사용한다.
- I/i는 공통 피스톤 시작-끝 표기를 사용한다.
- 피스톤은 기본 폭 5T, body_height 1T, shaft_width 0.90T, plate_height 1T를 사용한다.
- 피스톤은 `PISTON_LEFT`, body `(26T, 20T)`, travel 22T, cycle_seconds 1.18s, phase 0.00이다.
- i는 피스톤 플레이트가 왼쪽 끝까지 이동하는 최대 위치다.
- 박스는 I에서 i까지의 sweep 안에 놓인다. 피스톤은 박스를 왼쪽으로 밀어야 하며, 피스톤이 박스를 관통하면 안 된다.
- 스위치, 문, 새 SETTINGS 항목은 이 임시 테스트룸에서 사용하지 않는다.

## 의도한 풀이

1. 플레이어는 왼쪽에서 시작한다.
2. 좌향 피스톤이 Q 앵커로 배치된 박스를 왼쪽으로 미는 것을 확인한다.
3. 박스가 피스톤에 관통되거나 튀지 않고 안정적으로 밀리는지 확인한다.
4. 박스가 플레이어를 밀거나 벽에 막히는 경우 기존 압사 판정이 유지되는지 확인한다.
5. 확인 후 오른쪽의 E EXIT에 들어간다.

## 코드 반영 메모
- B는 `GravityBoxDef`로 만든다.
- I/i는 `PistonDevice`로 만든다.
- 피스톤은 박스를 관통하지 않고 플레이어와 같은 방식으로 이동 방향으로 민다.
- 새 SETTINGS 항목은 추가하지 않는다.
- 중력 방향 변경 기믹은 사용하지 않는다.
