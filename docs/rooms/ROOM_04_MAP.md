# ROOM 04 Map Draft

## 목적

이 파일은 ROOM 04의 현재 코드 맵을 문서로 옮긴 68x27 타일맵 초안이다.
사용자가 이 맵을 수정하면, 이후 src/game/rooms/room04.cpp를 이 타일맵 기준으로 반영한다.

ROOM 04는 천장에서 내려오는 피스톤 타이밍을 보고 오른쪽 EXIT로 이동하는 방이다.

## 맵 규격

- 전체 프레임: **68T x 27T**
- 1T = 40px
- 각 행은 반드시 68글자여야 한다.
- 전체 행 수는 반드시 27행이어야 한다.
- 빈 공간은 .으로 적는다.
- 화면 밖이나 사용하지 않는 공간도 맵 안에서는 #로 채운다.

## 범례

- # : 일반 벽 / 고정 플랫폼
- . : 플레이 가능한 빈 공간
- P : 플레이어 시작 위치
- I : 피스톤 본체 및 플레이트 이동 범위
- E : EXIT 배치 예약 영역

## 피스톤 표기 방식

피스톤은 실제 크기감을 보기 위해 I를 여러 칸으로 채워 표시한다.
이 초안에서 각 I 영역은 5T 폭의 피스톤 본체와 플레이트가 움직이는 세로 범위를 뜻한다.

피스톤 샤프트는 약 1.05T 폭이지만, 맵에서는 플레이트가 차지할 수 있는 전체 폭을 I로 표시한다.

## 의도한 풀이

1. 플레이어는 피스톤이 내려오는 타이밍을 확인한다.
2. 피스톤 사이의 빈 구간과 수축 타이밍을 이용해 오른쪽으로 이동한다.
3. 오른쪽의 E EXIT에 들어간다.

## 코드 반영 메모

- 연속된 #는 가능한 한 큰 RectF 플랫폼으로 병합한다.
- P, I, E는 플랫폼이 아니라 오브젝트 배치 마커로 처리한다.
- I는 PistonDevice로 만든다.
- 각 피스톤은 width 5T, body_height 1T, shaft_width 1.05T, plate_height 1T, travel 9T를 사용한다.
- E는 RoomDef.exit로 만든다.
