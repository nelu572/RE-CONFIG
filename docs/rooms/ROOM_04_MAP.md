# ROOM 04 Map Draft

## 목적

이 파일은 ROOM 04의 현재 코드 맵을 문서로 옮긴 68x27 타일맵 초안이다.
사용자가 이 맵을 수정하면, 이후 src/game/rooms/room04.cpp를 이 타일맵 기준으로 반영한다.

ROOM 04는 천장에서 내려오는 피스톤 타이밍을 보고 오른쪽 EXIT로 이동하는 방이다.

## 맵 규격

- 전체 프레임: **68T x 27T**
- 각 행은 반드시 68글자여야 한다.
- 전체 행 수는 반드시 27행이어야 한다.
- 공통 규격, 범례, 작성 원칙은 [ROOM_MAP_GUIDE.md](ROOM_MAP_GUIDE.md)를 따른다.

## 사용 오브젝트

- `#`, `.`, `P`, `I`, `i`, `E`

## 방별 오브젝트 메모

- I/i는 공통 피스톤 시작-끝 표기를 사용한다.
- 각 피스톤은 기본 규격인 width 5T, body_height 1T, plate_height 1T를 사용한다.
- 피스톤 샤프트는 약 1.05T 폭이지만, 맵에서는 플레이트의 시작/끝 위치와 sweep 범위를 우선한다.
- 여섯 개 피스톤은 모두 `PISTON_DOWN`이며, travel 9T를 사용한다.
- 공통 피스톤 주기는 1.10s이며, phase는 왼쪽부터 0.00, 0.06, 0.24, 0.30, 0.48, 0.54다.

## 의도한 풀이

1. 플레이어는 피스톤이 내려오는 타이밍을 확인한다.
2. 피스톤 사이의 빈 구간과 수축 타이밍을 이용해 오른쪽으로 이동한다.
3. 오른쪽의 E EXIT에 들어간다.

## 코드 반영 메모

- I/i는 `PistonDevice`로 만든다.
- 각 피스톤은 width 5T, body_height 1T, shaft_width 1.05T, plate_height 1T, travel 9T를 사용한다.
