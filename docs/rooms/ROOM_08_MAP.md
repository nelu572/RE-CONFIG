# ROOM 08 Map Draft

## 목적

ROOM 08은 이미 배운 박스·스위치·피스톤·음량을 한 줄로 연결하는 중후반 퍼즐이다.

> 먼저 무음 구역에서 박스로 통로를 열고, 중간의 스피커를 승강기로 사용해 상단 피스톤을 지난다.

스피커는 시작 장치가 아니라 **첫 문을 연 뒤 도착하는 이동 수단**이다. 시작 구역은 조용하고 안정적으로 유지해, 플레이어가 먼저 바꾼 결과(문이 열림)를 이해한 뒤 음량 기믹으로 넘어가게 한다.

## 맵 규격

- 전체 프레임: **48T x 54T**
- 각 행은 반드시 48글자여야 한다.
- 전체 행 수는 반드시 54행이어야 한다.
- 공통 규격, 범례, 작성 원칙은 [ROOM_MAP_GUIDE.md](ROOM_MAP_GUIDE.md)를 따른다.
- 상충하는 구현 변경은 [구현 변경 규칙](../IMPLEMENTATION_RULES.md)을 따른다.

## 사용 오브젝트

- `#`, `.`, `P`, `E`, `K`, `B`, `T`, `H`, `h`, `I`, `i`, `1`

## 방별 오브젝트 메모

- PLAYER 시작 위치는 `(4T, 50T)`이다. 시작 구역은 스피커 소스에서 약 `34T` 떨어져 있어 음량을 올려도 처음에는 영향을 받지 않는다.
- 박스는 `(8T, 50.5T, 1.5T, 1.5T)`에서 시작한다. 바닥 위에서 오른쪽으로 약 `4T`만 밀면 스위치에 닿는다.
- `1T`는 `(13.25T, 50T, 1T, 2T)`의 `PRESSURE_SWITCH_ANY`, `PRESSURE_SWITCH_MOUNT_RIGHT` 스위치 T1이다. 뒤의 고정 지지대 `(14T, 48T, 1T, 4T)`에 연결된다.
- `1H` 게이트 H1은 `(18T, 40T, 2T, 12T)`다. `1h` 목표 위치 `(32T, 40T, 2T, 12T)`까지 오른쪽으로 `14T` 이동한다. 시작 구역과 중간 구역을 나누는 문이며, 박스를 계속 옮길 필요 없이 이후 경로가 열린다.
- 중간 스피커 body는 `(37T, 39T, 5T, 7T)`, 소스는 `(39.25T, 43.62T)`다. 오른쪽 상승 피스톤이 올려 준 위치에서 음량을 높이면 플레이어를 위쪽 샤프트로 올린다.
- 상단 피스톤은 body `(18T, 8T)`, travel `8T`, 공통 주기 `1.10s`, phase `0.25`, `PISTON_DOWN`이다. 수축 헤드는 `I`(9행), 최대 확장 헤드는 `i`(17행)다.
- 오른쪽 상승 피스톤은 body `(34T, 52T)`, width `11T`, travel `13T`, 공통 주기 `1.10s`, `PISTON_UP`이다. 수축 plate `I`는 51행, 최대 확장 plate `i`는 38행이며 스피커 바로 아래까지 플레이어를 올린다.
- EXIT는 `(8T, 15T, 2T, 2T)`이다. 상단 발판에 도착한 뒤 피스톤이 수축한 타이밍에 왼쪽으로 지나가야 한다.

## 구역 역할

1. **시작 / 박스 게이트 (48T~52T)**: 스피커가 보이지 않는 평평한 시작 구역이다. 박스를 짧게 밀어 스위치에 붙이면, 오른쪽의 H 게이트가 움직여 다음 구역으로 가는 길이 생긴다.
2. **중간 접근 계단 / 상승 피스톤 (38T~49T)**: 열린 게이트 뒤의 넓은 계단이다. 마지막 발판에서 게이트를 넘어 오른쪽 상승 피스톤에 탑승한다.
3. **스피커 승강 샤프트 (18T~38T)**: 상승 피스톤이 스피커 높이까지 올려 주면, 음량을 높여 남은 수직 거리를 올라간다. 스피커는 이 구역에서 처음 등장하며, 박스나 시작 스위치에는 닿지 않는다.
4. **상단 피스톤 탈출 (2T~18T)**: 샤프트에서 나온 뒤, 수축한 피스톤 아래를 지나 EXIT로 간다.

## 의도한 풀이

1. 시작 구역에서 박스를 오른쪽으로 밀어 스위치를 누른다.
2. H 게이트가 오른쪽으로 물러나는 것을 보고, 열린 길로 들어간다. 박스는 스피커 범위 밖에 있으므로 그대로 스위치를 유지한다.
3. 넓은 계단을 올라 열린 게이트를 넘고, 오른쪽 상승 피스톤 위에 올라탄다.
4. 피스톤이 스피커 높이까지 올려 주면 음량을 높여 위로 상승하고, 상단 발판에서 음량을 낮춘다.
5. 피스톤이 수축한 타이밍에 왼쪽으로 지나 EXIT에 들어간다.

## 구현 시 충돌 / 물리 주의사항

- 스피커 소스와 박스 최종 중심의 거리는 약 `27.6T`로, 현재 음파 범위 `27T` 밖이다. 음량을 높여도 박스가 스위치에서 풀리지 않는다.
- H 게이트는 시작 시 계단 진입을 막고, 열린 뒤에는 마지막 계단 오른쪽의 빈 칸으로 이동한다. 이동 경로가 박스·스위치·고정 계단과 겹치지 않는다.
- 계단의 각 높이 차는 `3T` 이하다. 플레이어의 기본 점프 높이 안에서 오를 수 있으며, 마지막 게이트 넘기는 일반 점프 거리 안에 있다.
- 스피커는 하나만 사용한다. 파형 중첩과 시작 화면의 시각 소음을 만들지 않는다.
- 오른쪽 상승 피스톤은 스피커 진입용 발판이고, 상단 피스톤은 EXIT 전 통로 하나만 막는다. 실패해도 박스·스위치 풀이를 다시 할 필요 없이 하단에서 바로 재도전할 수 있다.

## 코드 반영 메모

- 기존 `SpeakerDevice`, `GravityBoxDef`, `PressureSwitchDevice`, `PressurePlatformDevice`, `PistonDevice`만 사용한다.
- 새 오브젝트·새 SETTINGS 항목·TYPE A 외형 변경은 하지 않는다.
- ROOM 08은 `exit_requires_pressure_switches = 0`을 사용한다. 스위치는 EXIT 잠금이 아니라 시작 구역 게이트를 여는 장치다.
