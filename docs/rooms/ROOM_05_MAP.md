# ROOM 05 Map Draft

## 목적

이 파일은 ROOM 05의 현재 코드 맵을 문서로 옮긴 48x27 타일맵 초안이다.
사용자가 이 맵을 수정하면, 이후 src/game/rooms/room05.cpp를 이 타일맵 기준으로 반영한다.

ROOM 05는 박스와 측면 스위치의 상호작용을 학습하는 방이다. 플레이어가 박스를 오른쪽으로 밀어 스위치를 누르면 EXIT 앞의 가로 장벽이 사라진다.

## 맵 규격

- 전체 프레임: **48T x 27T**
- 각 행은 반드시 48글자여야 한다.
- 전체 행 수는 반드시 27행이어야 한다.
- 공통 규격, 범례, 작성 원칙은 [ROOM_MAP_GUIDE.md](ROOM_MAP_GUIDE.md)를 따른다.

## 사용 오브젝트

- `#`, `.`, `P`, `B`, `Q`, `T`, `X`, `E`, `1`

## 방별 오브젝트 메모

- `1T`는 `1XXXXXXXX` 장벽 X1을 없애는 스위치 T1이다. 공통 스위치 규칙은 [압력 스위치와 이동 문](../design/pressure_switch.md)을 따른다.
- ROOM 05에서는 플레이어도 순간적으로 T를 누를 수 있지만, 장벽을 사라진 상태로 유지해 EXIT까지 가려면 B 박스가 필요하다.

## 의도한 풀이

1. 플레이어는 오른쪽 EXIT 앞의 X 장벽을 확인한다.
2. B 박스를 오른쪽으로 밀어 T 스위치를 누른다.
3. X 장벽이 사라지면 플레이어는 오른쪽의 E EXIT로 이동한다.

## 코드 반영 메모

- B, T, X의 변환은 [ROOM 맵 가이드](ROOM_MAP_GUIDE.md)를 따른다.
- 박스가 T1을 유지하는 동안 X1이 사라져 EXIT 통로가 열린다.
