# ROOM 05 Map Draft

## 목적

이 파일은 ROOM 05의 현재 코드 맵을 문서로 옮긴 68x27 타일맵 초안이다.
사용자가 이 맵을 수정하면, 이후 src/game/rooms/room05.cpp를 이 타일맵 기준으로 반영한다.

ROOM 05는 천장에서 내려오는 피스톤 타이밍을 보고 오른쪽 EXIT로 이동하는 방이다.

## 맵 규격

- 전체 프레임: **68T x 27T**
- 각 행은 반드시 68글자여야 한다.
- 전체 행 수는 반드시 27행이어야 한다.
- 공통 규격, 범례, 작성 원칙은 [ROOM_MAP_GUIDE.md](ROOM_MAP_GUIDE.md)를 따른다.

## 사용 오브젝트

- `#`, `.`, `P`, `I`, `i`, `E`

## 방별 오브젝트 메모

- 여섯 피스톤은 모두 아래로 움직이며, 각 travel은 `9T`다.
- 피스톤 간 phase는 왼쪽부터 `0.00`, `0.06`, `0.24`, `0.30`, `0.48`, `0.54`로 어긋난다.
- 공통 피스톤 규칙은 [피스톤](../design/piston.md), `I/i` 표기는 [ROOM 맵 가이드](ROOM_MAP_GUIDE.md)를 따른다.

## 의도한 풀이

1. 플레이어는 피스톤이 내려오는 타이밍을 확인한다.
2. 피스톤 사이의 빈 구간과 수축 타이밍을 이용해 오른쪽으로 이동한다.
3. 오른쪽의 E EXIT에 들어간다.
