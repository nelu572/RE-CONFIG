# ROOM 10 Map

> 이 문서는 현재 구현인 [room10.cpp](../../src/game/rooms/room10.cpp)의 ROOM 10 배치와 경로를 기록한다.
> 공통 동작은 [ROOM 맵 가이드](ROOM_MAP_GUIDE.md), [M1](../design/walker_enemy.md), [M2](../design/mm_enemy.md), [피스톤](../design/piston.md), [압력 스위치와 이동 문](../design/pressure_switch.md), [체크포인트](../design/checkpoint.md)를 따른다.

## 규격

- 프레임: 137T × 54T
- 1T: 40px
- 시작: P @ (3T, 49T)
- CHECKPOINT: C @ (63T, 8T)
- EXIT: E @ (135T, 44T)

## 사용 오브젝트

P, E, #, A, B, K, M1, M2, C, T, H/h, V/v, X, 1~5, I/i

## 공간과 흐름

1. START의 M1을 지나 BRICK과 스피커가 놓인 중앙 경로로 진입한다.
2. 하단 중앙 피스톤(x=64T~68T, y=43T → 25T)으로 중층에 오른다.
3. 중층 M2를 지나 3T/4T 갈림길을 선택한다. 최초 ROOM 진입에서 3번 또는 4번의 바닥 하나만 안전하게 유지된다. START 리스폰은 같은 선택을 유지하고, R 또는 ROOM 재진입은 다시 선택한다.
4. 각 갈림길의 상단 피스톤을 타고 상층으로 올라 C에서 합류한다.
5. C 뒤에는 오른쪽 상층을 따라 이동한 뒤 x=126T~131T의 열린 낙하 공간으로 내려온다.
6. B를 1T에 남겨 1H가 1h로 이동한 다리를 이용한다.
7. 5T와 5X를 지난 뒤 하층 M1/M2 공간을 통과해 2T/2V와 EXIT에 도달한다.

## 방별 오브젝트 메모

- M1은 (18.25T, 5.10T), (32.25T, 43.10T), (95.25T, 44.10T)에서 시작한다. M2는 (111.25T, 5.10T), (45.25T, 21.10T), (120.25T, 44.10T)에서 시작하며, 모두 실제 열린 진행 공간에 둔다.
- 세 피스톤은 모두 위 방향이다. 좌·우 상단 피스톤은 15T, 중앙 피스톤은 18T를 이동한다. 각 I/i sweep 안에는 고정 지형을 두지 않는다.
- 1T는 (110T, 33T)의 B와 연결되어 1H를 (103T, 33T)에서 (98T, 33T)로 이동시킨다.
- 3T/4T는 각각 3X/4X를 제어한다. ROOM 10 전용 선택 상태는 정답 쪽 X를 유지하고 오답 쪽 X만 소거한다.
- 5T는 하층 5X를 소거하는 함정이다.
- 2T는 2V를 열어 EXIT 바로 앞의 통로를 만든다.
- C 활성화 뒤의 사망과 5X 실패는 C에서 재시작한다.

## 구현 대조 메모

- 고정 지형, 오브젝트 좌표, M1/M2 생성 코드는 현재 room10.cpp와 일치한다.
- ROOM 10의 EXIT unlock은 2T만 확인한다. 다른 ROOM의 일반 EXIT unlock 규칙은 변경하지 않는다.
