# ROOM 06 Map Draft

## 목적

이 파일은 ROOM 06의 현재 코드 맵을 문서로 옮긴 57x27 타일맵 초안이다.
사용자가 이 맵을 수정하면, 이후 src/game/rooms/room06.cpp를 이 타일맵 기준으로 반영한다.

ROOM 06은 스피커, 박스, 스위치를 조합하는 방이다. 박스를 움직이는 동안에는 스피커가 플레이어를 EXIT 반대 방향으로 밀고, 스위치가 눌린 뒤 음량을 낮춰야 EXIT에 들어갈 수 있다.

## 맵 규격

- 전체 프레임: **57T x 27T**
- 각 행은 반드시 57글자여야 한다.
- 전체 행 수는 반드시 27행이어야 한다.
- 공통 규격, 범례, 작성 원칙은 [ROOM_MAP_GUIDE.md](ROOM_MAP_GUIDE.md)를 따른다.

## 사용 오브젝트

- `#`, `.`, `P`, `B`, `K`, `T`, `H`, `V`, `E`, `1`

## 방별 오브젝트 메모

- K 영역은 5T x 9T 스피커 본체를 뜻한다.
- 음파는 별도 타일로 표시하지 않는다.
- `1T`는 `PRESSURE_SWITCH_ANY` 스위치 T1이며, `1VV`와 `1HH`는 T1에 연결된 V1·H1 문이다.
- H는 `open_offset_x`, V는 `open_offset_y`를 사용한다.

## 의도한 풀이

1. 플레이어는 우측 계단을 올라가 EXIT 문 앞까지 갈 수 있지만, 닫힌 V 문은 통과할 수 없다.
2. K 스피커의 음량을 올리면 상단 레일의 B 박스가 오른쪽으로 밀려 T 스위치를 누른다.
3. V 문이 열리지만, 스피커가 켜진 상태에서는 EXIT를 향해 왼쪽으로 이동하기 어렵다.
4. 음량을 낮추면 박스는 스위치에 남아 문이 열린 상태를 유지하고, 플레이어는 왼쪽의 E EXIT로 이동한다.

## 코드 반영 메모

- K는 `SpeakerDevice`로 만든다.
- B는 `GravityBoxDef`로 만든다.
- T는 `PressureSwitchDevice`로 만들고 `PRESSURE_SWITCH_ANY`를 사용한다.
- H와 V는 모두 `PressurePlatformDevice`로 만들고, H는 `open_offset_x`, V는 `open_offset_y`를 사용한다.
- H와 V의 열림 거리는 이동 방향의 마커 길이와 같게 둔다.
