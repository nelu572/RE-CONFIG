# ROOM 00 Map Draft

## 목적

이 파일은 ROOM 00의 현재 코드 맵을 문서로 옮긴 48x27 타일맵 초안이다.
사용자가 이 맵을 수정하면, 이후 src/game/rooms/room00.cpp를 이 타일맵 기준으로 반영한다.

ROOM 00은 기본 이동과 EXIT 도달을 확인하는 첫 방이다. 별도 기믹 없이 바닥 플랫폼 위에서 오른쪽 EXIT로 이동한다.

## 맵 규격

- 전체 프레임: **48T x 27T**
- 1T = 40px
- 각 행은 반드시 48글자여야 한다.
- 전체 행 수는 반드시 27행이어야 한다.
- 빈 공간은 .으로 적는다.
- 화면 밖이나 사용하지 않는 공간도 맵 안에서는 #로 채운다.

## 범례

- # : 일반 벽 / 고정 플랫폼
- . : 플레이 가능한 빈 공간
- P : 플레이어 시작 위치
- E : EXIT 배치 예약 영역

## 의도한 풀이

1. 플레이어는 시작 위치에서 오른쪽으로 이동한다.
2. 바닥 플랫폼을 따라 이동해 E EXIT에 들어간다.

## 코드 반영 메모

- 연속된 #는 가능한 한 큰 RectF 플랫폼으로 병합한다.
- P와 E는 플랫폼이 아니라 오브젝트 배치 마커로 처리한다.
- E는 RoomDef.exit로 만든다.
- 현재 코드 기준 플랫폼은 { T(6), T(21), T(36), T(6) } 하나이다.
