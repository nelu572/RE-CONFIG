# ROOM 09 Temporary Platformer Map

> This is the active temporary layout implemented by `src/game/rooms/room09.cpp`.
> The previous layout is retained in [ROOM_09_MAP_SAVED.md](ROOM_09_MAP_SAVED.md).

## Map Scale

- 1T = 40px
- Frame: 168T x 27T
- The ASCII tile map below is the sole placement source for this temporary layout.

## Used Objects

- `P`: player start
- `#`: fixed platform
- `M`: walker enemy start area
- `I` / `i`: retracted / fully extended piston plate
- `B`: gravity box start area
- `A`: BRICK wall
- `K`: speaker body
- `T`: pressure switch
- `H` / `V` / `h` / `v`: closed/open moving door markers
- `X`: pressure barrier
- `1`–`4`: switch and linked door/barrier IDs
- `C`: checkpoint
- `E`: exit

## Temporary Layout Notes

- Four semi-enclosed chambers alternate a cramped low route with a taller escape route; the doors visibly change each chamber's silhouette.
- Speakers sit at chamber mouths or ceiling pockets so their sound fields obstruct passage and force timing, instead of becoming loose decoration.
- Four pistons serve distinct roles: an upward lift, a descending blocker, another upward lift, and a horizontal pusher inside a narrow lane.
- Four pressure links respectively raise a vertical gate, fade a barrier, slide a horizontal platform, and raise the final gate.
- Four BRICK groups create hard boundaries and pockets; three boxes offer alternative switch weights in the enclosed routes.
- Five walker areas occupy lower lanes and make short corridors hazardous when the player approaches.
