# ROOM 03 Map Draft

## 목적

이 파일은 ROOM 03의 현재 코드 맵을 문서로 옮긴 48x27 타일맵 초안이다.
사용자가 이 맵을 수정하면, 이후 src/game/rooms/room03.cpp를 이 타일맵 기준으로 반영한다.

ROOM 03은 중앙 고정 플랫폼 때문에 좁아진 통로를 통과해 오른쪽 EXIT로 이동하는 방이다.

## 맵 규격

- 전체 프레임: **48T x 27T**
- 각 행은 반드시 48글자여야 한다.
- 전체 행 수는 반드시 27행이어야 한다.
- 공통 규격, 범례, 작성 원칙은 [ROOM_MAP_GUIDE.md](ROOM_MAP_GUIDE.md)를 따른다.

## 사용 오브젝트

- `#`, `=`, `.`, `P`, `E`

## 방별 오브젝트 메모

- 중앙 플랫폼은 현재 코드에서 `{ T(14), T(4), T(20), T(16.25f) }` 크기다.
- ASCII 맵에서는 16행의 `#`와 마지막 0.25T 끝단의 `=`로 표시하고, 코드 반영 시 실제 높이 16.25T를 유지한다.

## 의도한 풀이

1. 플레이어는 중앙 플랫폼 왼쪽에서 시작한다.
2. 중앙 플랫폼 아래쪽의 좁은 통로를 이용해 오른쪽으로 이동한다.
3. 오른쪽의 E EXIT에 들어간다.
