# ROOM 03 Map Draft

## 목적

이 파일은 ROOM 03의 현재 코드 맵을 문서로 옮긴 48x27 타일맵 초안이다.
사용자가 이 맵을 수정하면, 이후 src/game/rooms/room03.cpp를 이 타일맵 기준으로 반영한다.

ROOM 03은 중앙 고정 플랫폼 때문에 좁아진 통로를 통과해 오른쪽 EXIT로 이동하는 방이다.

## 맵 규격

- 전체 프레임: **48T x 27T**
- 1T = 40px
- 각 행은 반드시 48글자여야 한다.
- 전체 행 수는 반드시 27행이어야 한다.
- 빈 공간은 .으로 적는다.
- 화면 밖이나 사용하지 않는 공간도 맵 안에서는 #로 채운다.

## 범례

- # : 일반 벽 / 고정 플랫폼
- . : 플레이 가능한 빈 공간
- P : 플레이어 시작 위치
- E : EXIT 배치 예약 영역

## 중앙 플랫폼 표기 방식

중앙 플랫폼은 현재 코드에서 { T(14), T(4), T(20), T(16.25f) } 크기다.
ASCII 맵에서는 점유감을 확인하기 위해 17행 높이의 #로 표시하고, 코드 반영 시 실제 높이 16.25T를 유지한다.

## 의도한 풀이

1. 플레이어는 중앙 플랫폼 왼쪽에서 시작한다.
2. 중앙 플랫폼 아래쪽의 좁은 통로를 이용해 오른쪽으로 이동한다.
3. 오른쪽의 E EXIT에 들어간다.

## 코드 반영 메모

- 연속된 #는 가능한 한 큰 RectF 플랫폼으로 병합한다.
- P와 E는 플랫폼이 아니라 오브젝트 배치 마커로 처리한다.
- E는 RoomDef.exit로 만든다.
- 중앙 플랫폼은 실제 코드처럼 높이 T(16.25f)를 유지한다.
